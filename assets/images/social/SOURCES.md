# منابع نشان‌های پیام‌رسان

این فایل‌ها به‌صورت محلی نگهداری می‌شوند تا قالب هیچ درخواست خارجی در زمان اجرا نداشته باشد. نام‌ها و نشان‌های تجاری متعلق به صاحبان مربوط هستند و فقط برای شناسایی لینک کانال استفاده می‌شوند.

| فایل | منبع |
|---|---|
| `eitaa.svg` | مجموعهٔ Dashboard Icons، نشان Eitaa: `homarr-labs/dashboard-icons/svg/eitaa.svg`؛ رنگ برای قرارگیری روی زمینهٔ برند سفید شده است. |
| `bale.svg` | مجموعهٔ Dashboard Icons، نشان Bale: `homarr-labs/dashboard-icons/svg/bale.svg` |
| `rubika.svg` | وکتور نشان Rubika از `HosseinZadehDev/CampGamingMOTD/icons/rubika.svg`؛ رنگ برای قرارگیری روی زمینهٔ برند سفید شده است. |
| `igap.png` | مخزن رسمی کلاینت اندروید iGap، `KianIranian-STDG/iGap-Android`؛ بخش نماد از فایل لوگوی رسمی جدا و برای وب کوچک‌سازی شده است. |
| `soroush.svg` | مجموعهٔ Socicon، `Ybbet/socicon/svg/soroush.svg`؛ رنگ برای قرارگیری روی زمینهٔ برند سفید شده است. |

نسخه‌های SVG فاقد script و ارجاع شبکه‌ای هستند؛ PNG آی‌گپ ۱۲۸×۱۲۸ و شفاف است.
