# پادکست استاندارد و همگام‌سازی Sonaar

## ساختار داده

پست‌تایپ پادکست همان شناسهٔ موجود `sr_playlist` است؛ بنابراین سه پادکست قبلی و همهٔ شناسه‌ها، URLها و روابط taxonomy بدون تبدیل باقی می‌مانند.

قسمت‌های جدید در متای canonical زیر ذخیره می‌شوند:

```text
_evented_podcast_tracks
```

هر ردیف شامل `title`، `artist`، `description`، `attachment_id` و `audio_url` است. صفحهٔ عمومی ابتدا این متا را می‌خواند و فقط در نبود آن به `alb_tracklist` افزونهٔ Sonaar برمی‌گردد.

## افزودن پادکست جدید

1. در مدیریت وردپرس وارد «پادکست‌ها ← افزودن» شوید.
2. عنوان، توضیح، تصویر شاخص و در صورت نیاز دسته را وارد کنید.
3. در متاباکس «قسمت‌های صوتی» روی «افزودن فایل صوتی» بزنید.
4. فایل را از Media Library انتخاب کنید یا URL/stream خارجی وارد کنید.
5. عنوان، گوینده و توضیح قسمت را وارد و ترتیب قسمت‌ها را تنظیم کنید.
6. پادکست را منتشر کنید.

## همگام‌سازی داده‌های قدیمی

از مسیر «پادکست‌ها ← همگام‌سازی قسمت‌ها» ابزار را اجرا کنید. این عملیات:

- همهٔ رکوردهای `sr_playlist` را بررسی می‌کند؛
- `alb_tracklist` را به `_evented_podcast_tracks` منتقل می‌کند؛
- متای Sonaar را حذف یا بازنویسی نمی‌کند؛
- دادهٔ canonical موجود را بازنویسی نمی‌کند؛
- قابل اجرای مجدد و idempotent است.

پیش از deploy واقعی تهیهٔ backup دیتابیس توصیه می‌شود، هرچند ابزار هیچ دادهٔ قدیمی را حذف نمی‌کند.
