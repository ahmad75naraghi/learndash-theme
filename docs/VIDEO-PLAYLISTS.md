# مدیریت پلی‌لیست ویدئو

## ساختار استاندارد

هر نوشته از post type با کلید `clip` همهٔ قسمت‌های خود را در **یک** رکورد post meta با کلید زیر نگه می‌دارد:

```text
_evented_video_playlist
```

مقدار، آرایه‌ای مرتب از آیتم‌های زیر است:

```php
array(
    array(
        'title'         => 'عنوان قسمت',
        'description'   => 'توضیح کوتاه',
        'video_url'     => 'https://example.com/video.mp4',
        'thumbnail_id'  => 123,
        'thumbnail_url' => 'https://example.com/poster.jpg',
    ),
)
```

این متا با `register_post_meta()`، schema مشخص REST، کنترل دسترسی و sanitize callback ثبت شده است.

## افزودن قسمت در Gutenberg

1. از مدیریت وردپرس وارد «ویدئوها» شوید و یک ویدئو را ویرایش کنید.
2. در کادر «قسمت‌های ویدئو»، «افزودن ویدئو» را بزنید.
3. عنوان، آدرس فایل ویدئو و متن کوتاه را وارد کنید.
4. با «انتخاب تصویر»، thumbnail را از Media Library انتخاب کنید.
5. با فلش‌ها ترتیب پخش را تغییر دهید یا با «حذف» یک قسمت را بردارید.
6. نوشته را به‌روزرسانی کنید. تمام ردیف‌ها با همان ترتیب در یک meta_value ذخیره می‌شوند.

ردیف بدون URL معتبر هنگام ذخیره کنار گذاشته می‌شود. URL، متن و شناسهٔ تصویر در سمت سرور نیز پاک‌سازی می‌شوند.

## تبدیل داده‌های قدیمی Elementor

از مسیر زیر وارد ابزار مهاجرت شوید:

```text
ویدئوها ← یکپارچه‌سازی پلی‌لیست‌ها
```

این ابزار برای هر `clip`، آیتم‌های `settings.tabs` ویجت `video-playlist` را از `_elementor_data` می‌خواند و در متای استاندارد می‌نویسد. اگر پلی‌لیست ساختاریافته وجود نداشته باشد، URLهای مستقیم پراکنده در متاهای قدیمی نیز بازیابی و استاندارد می‌شوند.

- داده‌های Elementor حذف نمی‌شوند.
- نوشته‌ای که از قبل `_evented_video_playlist` دارد بازنویسی نمی‌شود.
- اجرای دوبارهٔ ابزار امن و idempotent است.
- در صفحهٔ ویرایش یک ویدئوی قدیمی نیز آیتم‌ها پیش‌نمایش می‌شوند و با اولین «به‌روزرسانی» در ساختار جدید ذخیره خواهند شد.

## نمایش عمومی

صفحهٔ تکی ویدئو ابتدا متای استاندارد را می‌خواند. فقط اگر متای استاندارد وجود نداشته باشد، برای سازگاری عقب‌رو داده‌های Elementor/قدیمی را می‌خواند. قسمت‌ها با thumbnail، عنوان و توضیح زیر پلیر نمایش داده می‌شوند و انتخاب هر فایل مستقیم، منبع پلیر بالای صفحه را عوض می‌کند.
