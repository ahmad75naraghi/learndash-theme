# مرکز گزارش‌گیری LearnDash

نسخهٔ داخلی قالب جایگزین افزونهٔ قدیمی `report_courses` است و از منوی «گزارش‌گیری» در پیشخوان در دسترس قرار می‌گیرد.

## بخش‌ها

- **نمای کلی:** تعداد تکمیل دوره، کاربران یکتا، شرکت در آزمون و تکمیل‌های ۳۰ روز اخیر.
- **تکمیل دوره‌ها:** جستجو، فیلتر دوره و بازهٔ تاریخ، تعداد ردیف قابل تنظیم و صفحه‌بندی.
- **نتایج آزمون‌ها:** فیلتر دوره، شناسه آزمون، بازهٔ تاریخ و وضعیت قبولی؛ نمایش نمره، امتیاز، IP، شماره کارت و فایل پاسخ تشریحی.

## خروجی

CSV با BOM UTF-8 برای Excel و JSON مستقیماً روی سرور و در chunkهای ۵۰۰تایی تولید می‌شوند. بنابراین تمام رکوردهای مطابق فیلتر صادر می‌شوند، بدون اینکه جدول چندده‌هزارردیفی در مرورگر ساخته شود یا SheetJS/CDN بارگذاری شود.

سلول‌هایی که ممکن است در Excel به‌عنوان formula اجرا شوند خنثی می‌شوند. خروجی فقط با capability `manage_options` و nonce معتبر قابل دریافت است.

## کارایی

- user meta پیش از رندر هر صفحه به‌صورت گروهی cache می‌شود.
- activity meta آزمون با conditional aggregation در یک query خوانده می‌شود.
- شمارش سادهٔ آزمون‌ها در نبود فیلتر قبولی به جدول meta متصل نمی‌شود.
- جدول UI صفحه‌بندی‌شده است و سقف ۲۰۰ ردیف در هر صفحه دارد.
- خروجی کامل به‌صورت stream و chunked تولید می‌شود.

## IP و شماره کارت

IP فقط از `REMOTE_ADDR` معتبر گرفته و روی `activity_id` واقعی آزمون ذخیره می‌شود؛ headerهای proxy قابل جعل به‌صورت پیش‌فرض پذیرفته نمی‌شوند. گزارش برای داده‌های افزونهٔ قدیمی نیز fallback دارد.

shortcode قبلی `[update_meta_value]` حفظ شده، اما اکنون nonce، اعتبارسنجی دقیق ۱۶ رقم، ارقام فارسی/عربی، نمایش ماسک‌شده و رابط responsive دارد. تا پیش از ثبت شماره کارت، دکمهٔ شروع آزمون پنهان می‌شود.

## مهاجرت

پس از deploy، افزونهٔ قدیمی `report_courses` را غیرفعال کنید. قالب در دورهٔ هم‌پوشانی hookهای شناخته‌شدهٔ افزونه را حذف می‌کند تا منو و ثبت IP تکراری ایجاد نشود. هیچ جدول یا داده‌ای حذف نمی‌شود.
